Adding Projects
===============

For users adding projects to VERTEX involves a number of stages, starting with generating a project folder with the appropriate structure, submitting the folder to the ISARIC data team (:email:`data@isaric.org`) for review and deployment, viewing the project in VERTEX, and managing project access via the `ISARIC Accounts <https://account.isaric.org/>`_ service.

This is described in the :ref:`user guide <adding-a-project>`. For VERTEX maintainers there are :ref:`notes <maintainer-notes>` describing the full project deployment maintenance, with technical notes to help with maintenance and troubleshooting.
